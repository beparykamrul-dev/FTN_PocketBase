আপনার চাওয়া অনুযায়ী **Encoder**, **Decoder**, এবং **Hugging Face**—এই তিনটিকে একত্রিত না রেখে সম্পূর্ণ **আলাদা আলাদা ৩টি ডেডিকেটেড মডিউল** হিসেবে ভাগ করে দেওয়া হলো।

এখন আপনার সাইডবারে প্রতিটি ফিচার নিজস্ব মডিউল হিসেবে থাকবে:
1. 📊 **Dashboard** (সিস্টেম স্ট্যাটাস)
2. 📁 **Notes Module** (এনক্রিপ্টেড নোট ও ফাইল স্টোরেজ)
3. 🔐 **Encoder Module** (শুধুমাত্র টেক্সটকে সিকিউর হ্যাশ/কোডে রূপান্তর করার ডেডিকেটেড মডিউল)
4. 🔓 **Decoder Module** (হ্যাশ/কোড থেকে আসল টেক্সট পুনরুদ্ধার করার ডেডিকেটেড মডিউল)
5. 🤗 **Hugging Face Module** (ওপেন এআই মডেল দিয়ে টেক্সট জেনারেশন)
6. 🧠 **Pydantic AI Module** (লোকাল পাইথন ভ্যালিডেটেড এজেন্ট)

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field

app = FastAPI()
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])

class Query(BaseModel):
    task: str = Field(..., min_length=1)

@app.post("/run")
def run_agent(q: Query):
    return {
        "status": "success",
        "engine": "Pydantic-AI Core",
        "output": f"Validated task: {q.task.strip()}"
    }

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000, log_level="warning")
EOF

        const PB = window.location.origin;

        // Navigation Switcher

        // Cipher Core Functions
        const ftnEncode = t => btoa(unescape(encodeURIComponent(t + "|" + SALT)));

            try { return decodeURIComponent(escape(atob(h))).split("|")[0]; }
            catch(e) { return "Invalid Hash!"; }

        async function saveNote() {

            fd.append("title", ftnEncode(title));
